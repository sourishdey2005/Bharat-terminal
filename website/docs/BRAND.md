# Brand — Bharat Terminal

Made by Sourish Dey. MIT Licensed.

- Name: **Bharat Terminal** — stacked below the logo everywhere (header + footer lockup, amber `#FFB000`, extrabold).
- Logo: `public/logo.png` (canonical source: `https://res.cloudinary.com/dodhvvewu/image/upload/v1790695957/app-1024_mfa8ek.png`, mirrored locally) — amber `#FFB000` square, black "BT" + candlesticks. Favicon + header/footer lockup + `app/icon.png` + `app/apple-icon.png` all use this PNG. No SVG monogram.
- Primary brand color: amber `#FFB000` (hover `#FFC93C`, pressed `#D68F00`).
- Background: void `#050608` (dark default). Light theme: white + dark-gold `#B8860B`.
- Saffron `#FF9933` and India green `#138808`: **only** for the "Made in India" badge / flag dividers.
- Tagline: "Bloomberg power. Zero cost. Made in India."
- Author credit "Made by Sourish Dey" appears in: every footer, hero badge, about page, meta tags, JSON-LD, 404, loading state, console log, README, LICENSE, package.json, OG images.
- Type: Inter (UI), Inter Tight 800 (hero H1), JetBrains Mono (code).
- No kitsch. Linear/Stripe-grade restraint.
