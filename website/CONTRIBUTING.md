# Contributing — Bharat Terminal Website

Made by Sourish Dey. MIT Licensed.

1. Fork + branch (`feat/your-change`).
2. `cd website && npm install && npm run dev`.
3. Keep TypeScript strict, no unused imports.
4. Keep amber `#FFB000` as the only primary brand color.
5. Saffron `#FF9933` only for the "Made in India" badge.
6. Test mobile (<640px), keyboard nav, and both themes.
7. Open a PR with screenshots + Lighthouse note.
